# Interface decisions

The screen serves API/MCP maintainers comparing onboarding materials and developers completing a first task. Its primary job is creating a bounded run and finding verification evidence.

Visual direction: an instrument workspace with a teal evidence rail, quiet blue surfaces and readable structured results. The material versions and run status provide the recognizable structure. No decorative animation or remote assets.

Palette: ink #193540; teal #147f86; muted #526c76; line #c8d9de; surface #f3f8f9; error #a13d3d. System UI handles headings/body, Consolas handles utility data. The layout separates setup from evidence and links feedback to verified revisions. Narrow screens stack the same controls; focus and status announcements support keyboard use.
